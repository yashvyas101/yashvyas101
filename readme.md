## 📌 Featured Projects

### 🚆 [RailNiyojan](https://github.com/sumedhamandloi/RailNiyojan)
**Intelligent AI-Powered Automatic Railway Block Planning System**  
*Developed for the Smart India Hackathon problem statement*

- **Problem & Solution**: Railway corridor maintenance requires tight coordination across multiple departments (track engineering, signaling & telecommunication, and overhead electrical lines). RailNiyojan automates scheduling and conflict resolution to minimize train traffic disruption and maximize track safety.
- **Key Architecture & Contributions**:
  - Implemented multi-department maintenance task ingestion and cross-departmental dependency tracking.
  - Engineered backend planning logic and scheduling services in Node.js/Express with relational schema mapping in SQL.
  - Integrated optimization and conflict detection routines to eliminate schedule collisions and resource bottlenecks.
- **Tech Stack**: `Node.js` • `Express.js` • `SQL (MySQL/PostgreSQL)` • `Dependency Resolution` • `RESTful APIs`

---

### 🎙️ [Wani RAG (VAANI)](https://github.com/yashvyas101/Vaani)
**Voice-First Multilingual Retrieval-Augmented Generation (RAG) Assistant**  
*Live Demo: [vaani-rag-lime.vercel.app](https://vaani-rag-lime.vercel.app/)*

- **Problem & Solution**: Removes language and interface barriers by allowing users to speak naturally in **English, Hindi, or Marathi** to retrieve accurate, evidence-backed answers from domain knowledge bases.
- **Key Architecture & Contributions**:
  - **Speech-to-Text Pipeline**: Real-time spoken query transcription utilizing Sarvam AI.
  - **Multilingual Embeddings**: Dense multilingual vector representation using **BAAI BGE-M3**, running locally with **Intel OpenVINO** for reduced latency and offline efficiency.
  - **Vector Retrieval**: Semantic similarity search with **Qdrant Vector DB** for top-5 relevant context chunk extraction.
  - **Evidence Grounding & Safe Fallback**: Response generation via Google Gemini with context-grounding and automatic fallback responses when evidence is insufficient, preventing hallucinations.
- **Tech Stack**: `Python` • `Qdrant` • `BAAI BGE-M3` • `OpenVINO` • `Google Gemini API` • `Sarvam AI` • `RAG Architecture`

### 🎤 [Voice Audit](https://github.com/yashvyas101/Voice-Audit)
**AI-Powered Voice Assistant for Google Workspace Automation**

- **Problem & Solution**: Bridges natural conversational commands directly into Google Workspace workflows—allowing users to schedule meetings, manage task boards, and draft emails purely through voice or text.
- **Key Architecture & Contributions**:
  - Multi-input processing using the Web Speech API for voice capture and real-time transcription.
  - Context and intent extraction driven by **Google Gemini 2.5 Flash**, intelligently identifying dates, participants, actions, and priority levels.
  - Automated integration with **Google Calendar API, Google Tasks API, and Gmail API** via an Express.js backend.
  - Secure authentication with Firebase Auth (Google OAuth 2.0) and chat session persistence in Firestore.
- **Tech Stack**: `React 19` • `TypeScript` • `Node.js` • `Express` • `Gemini 2.5 Flash` • `Firebase Auth & Firestore` • `Google Workspace APIs`
